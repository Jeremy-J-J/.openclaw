# 2026-04-04 工作记录

## 微博热搜抓取 - Chrome MCP 最佳实践

### 背景
用户要求通过 Chrome MCP 方式操作 Chrome 浏览器访问微博首页，获取热搜榜单。

### 操作步骤
1. 先用 `browser(action=status, profile="user")` 确认 Chrome MCP 连接状态
2. 确认 `transport: "chrome-mcp"` 和 `running: true` 后，使用 `browser(action=open, profile="user", url="https://weibo.com")` 打开微博
3. 页面加载后，用 `browser(action=snapshot, profile="user", targetId="<tabId>")` 获取页面快照
4. 从 snapshot 的 accessibility tree 中提取热搜内容（位于 `link "N xxx 热度值"` 的元素中）

### 关键要点
- **必须先确认 status**，确认 `transport: "chrome-mcp"` 后才能操作，否则会报 timeout
- **profile 要用 `"user"`** 而非默认的 `"openclaw"`，这样才能操作用户已登录的 Chrome
- 微博热搜区域在首页右侧 snapshot 中，格式为 `link "N 热搜词 热度值"`
- 之前用 agent-browser 也能抓到数据，但用户明确要求用 Chrome MCP 的方式

### 涉及工具
- `browser` 工具（Chrome MCP transport）
