## 微信公众号发布最佳实践（2026-04-10 更新）

### 问题诊断
- wenyan-cli v2.0.4 在 Node v23.6.0 下静默退出（EXIT:0但无输出）
- wenyan-cli v1.0.11 在 Node v23.6.0 下报 `css.replace is not a function`
- Node 版本要求：v2.x 需要 `^20.19.0 || ^22.12.0 || >=24.0.0`（v23.x 不兼容）

### 最终成功的方案：直接调微信 API
流程：
1. 获取 access_token（curl 调用微信 API，IP需在白名单）
2. Python 手工做 Markdown → HTML 转换
3. 上传封面图获取 thumb_media_id（material/add_material）
4. 调用 draft/add 上传到草稿箱

### wenyan-cli 是什么
- 全称：@wenyan-md/cli，微信公众号 Markdown 发布工具
- 作者：caol64，GitHub: github.com/caol64/wenyan-mcp
- 功能：将 Markdown 文件（含 frontmatter 元数据）转换为微信公众号可用的 HTML，并上传至草稿箱
- 支持主题（lapis等）、代码高亮、封面图自动上传
- 本质：封装了微信公众号的 draft/add 和 material/add_material API

### wenyan-cli 依赖的 Node 版本
- v2.0.x：需要 Node ^20.19.0 || ^22.12.0 || >=24.0.0（不支持 v23.x）
- v1.0.11：支持范围更广，但存在 CSS 处理模块兼容问题
- 当前环境：Node v23.6.0，不兼容 v2.0.x，也无法正常运行 v1.0.11

### 凭证文件格式（重要！）
`~/.config/wenyan-md/credential.json` 必须为以下格式：
```json
{
  "wechat": {
    "wx1767b589cc50950f": {
      "appId": "wx...",
      "appSecret": "..."
    }
  }
}
```
注意：必须有 `wechat` 外层包装，不是直接以 appId 为 key

### 微信公众号直接 API 方案（成功案例）
- IP白名单：需将当前公网IP加入公众号后台
- 获取token：`curl "https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid=APPID&secret=APPSECRET"`
- 上传封面：`POST https://api.weixin.qq.com/cgi-bin/material/add_material?access_token=TOKEN&type=image`
- 上传草稿：`POST https://api.weixin.qq.com/cgi-bin/draft/add?access_token=TOKEN`
