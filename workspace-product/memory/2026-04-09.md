## 论文研读最佳实践（两次实战总结）

### 流程规范
1. PDF下载 → text提取 → 图片提取（PyMuPDF fitz）
2. 图片处理：宽度>900px → sips -Z 900缩放 → img402.dev上传
3. 报告写入 research-papers/{论文简称}_研读报告.md（不要放memory/）
4. 图表URL用HTML格式嵌入，居中+宽度控制

### 关键经验
- img402.dev 上传：curl -s -X POST + python3 json解析，~60s超时
- 论文简称：从标题提取关键词作为文件名（如DeepSeek-R1、YOLO）
- 图表提取优先用PyMuPDF原生图片，不使用整页截图
- 研读报告模板固定：Part A（深度学术解析）+ Part B（核心逻辑提炼）
- 每次研读后更新当日memory/YYYY-MM-DD.md，记录产出路径
