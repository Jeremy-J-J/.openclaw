### Step by Step 操作流程

**Step 1: 获取 access_token**
```bash
source skills/wechat-mp-publisher/wechat.env
curl "https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid=${WECHAT_APP_ID}&secret=${WECHAT_APP_SECRET}"
```

**Step 2: 上传封面图（获取 thumb_media_id）**
```bash
curl -X POST "https://api.weixin.qq.com/cgi-bin/material/add_material?access_token=${TOKEN}&type=image" \
  -F "media=@charts/封面图.png;type=image/png"
```

**Step 3: 上传正文所有图片（获取 mmbiz URL）**
```bash
for f in charts/fig_*.png charts/fig_*.jpeg; do
  TYPE=$(echo $f | grep -q png && echo "image/png" || echo "image/jpeg")
  RESP=$(curl -s -X POST "https://api.weixin.qq.com/cgi-bin/material/add_material?access_token=${TOKEN}&type=image" \
    -F "media=@$f;type=$TYPE")
  URL=$(echo $RESP | python3 -c "import sys,json; print(json.load(sys.stdin).get('url',''))")
  echo "$f: $URL"
done
```

**Step 4: Markdown 转 HTML 并上传草稿箱**
- 由 Python 脚本完成（见下方完整转换逻辑）

**Step 5: 上传草稿箱**
```bash
curl -X POST "https://api.weixin.qq.com/cgi-bin/draft/add?access_token=${TOKEN}" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d @/tmp/wechat_article.json
```

### 关键经验（踩坑总结）

#### 1. 图片 URL 必须用微信素材库地址
- **不能**用 img402.dev 等外部图床链接，微信会过滤
- 先用 `material/add_material` 上传图片，获取 `mmbiz.qpic.cn` 地址
- 替换研读报告 `charts/` 目录图片的 URL

#### 2. LaTeX 公式必须转文字描述
- 微信公众号不支持 LaTeX
- 将 `$$...$$` 公式块替换为 1-2 句话文字描述

#### 3. HTML 标签不能转义
- `<p align="center"><img src="...">` 不能写成 `&lt;p`
- Markdown 中的 HTML 标签行（如图片 caption）直接保留，不经过 escape 函数

#### 4. WeChat 不支持空行，用 CSS margin-top 替代
- WeChat 编辑器会忽略纯空行（`''`）
- 用 `<br/><br/>` 也不行（被过滤）
- **正确方案**：用 CSS `style="margin-top:20px"` 加在顶级章节标题的 `<p>` 上

#### 5. margin-top 只加在顶级章节（H2 和顶級 H3）
- **加 margin-top**：H2 标题（## 开头）、顶级 H3 标题（如 `### 1. 引言`、`### 2. 模型架构`）
- **不加 margin-top**：子章节 H3（如 `#### 1.1`、`#### 2.1`）
- 判断方法：H2 全部加；H3/H4 用正则匹配 `^\d+\.\s+`（顶级章节格式）来判断

### Markdown → HTML 转换逻辑（最终版）

```
输入：research-papers/{论文简称}_研读报告.md

处理流程：
1. 读取 MD 内容，替换 img402.dev URL → mmbiz URL
2. 去除 Part B 及以后内容
3. 修改文章标题（更吸引人，如"谷歌一篇论文改变了AI史：Attention Is All You Need"）

逐行处理：
- LaTeX 残留行（$$）：跳过
- 表格行（| 开头）：收集到 table_rows，输出 HTML <table>
  - 信息类表格（项目/维度/指标 两列）：转 <p><strong>key</strong>：value</p>
  - 复杂表格：转标准 HTML table
- H1 标题（#）：跳过（标题已在外部设置）
- H2 标题（##）：顶级章节，加 margin-top:20px；跳过"核心信息"/"Part A"/"Part B"等元标题
- H3/H4 标题：
  - 顶级章节（匹配 ^\d+\.\s+）：加 margin-top:20px
  - 子章节（#### 1.1 等）：不加 margin
- HTML 标签行（<p align="center"><img 等）：直接保留
- 代码块（```）：转 <pre><code>
- 普通段落：转 <p>text</p>

段落间距：
- 只在顶级章节标题（H2/H3顶级章节）前有 margin-top:20px
- 段落之间无额外空行，段落内文字连续

图片处理：
- 研读报告中的图片是 HTML <img> 标签格式（width=600/900）
- 替换 src 中的 img402.dev URL 为微信 mmbiz URL
- Caption（如"图1：xxx"）直接作为下一行 <p> 输出

最终输出：
- HTML content 直接作为 article.content 上传
- title：吸引人的修改后标题
- author：极智视界
- thumb_media_id：封面图上传后的 media_id
```

### 研读报告 Markdown 格式规范

```
标题：吸引人的修改后标题（不用"研读报告"等直白字样）
正文：
- 核心信息：直接写裸文本，如"论文标题：xxx"，不用写 HTML 标签
- 背景/目标、方法、结果、结论：直接写裸文本段落
- 顶级章节（### 1. xxx、### 2. xxx）：加间距
- 子章节（#### 1.1 xxx、#### 2.1 xxx）：不加间距
- 列表：用 Markdown "- " 格式，不用 HTML
- LaTeX 公式：转文字描述
- 图片：先用 img402.dev 图床，转换时替换为 mmbiz
- 不要写 HTML 标签在 Markdown 里
```

### Markdown → HTML 转换要点

```
1. 研读报告 markdown 中不要写 HTML 标签，统一用纯 Markdown
2. LaTeX 公式：替换为文字描述，跳过 $$
3. H2/H3 顶级章节标题：非第一个时加 margin-top:20px
4. H3/H4 子章节：都不加 margin-top
5. 分隔线 ---：转 <hr/>
6. 顶级章节标题紧跟 <hr/>：也要加 margin-top:20px（prev_was_hr 标志）
7. 列表项 - ：转 <p>text</p>，不用 <ul><li>
8. 表格单元格：先 strip_md_format 再 inline_format，避免双重加粗
9. HTML 行（如 <p align="center"><img）：直接 append，不 escape
10. 纯 <p> 即可（WeChat 默认左对齐），不需要 text-align CSS
```
