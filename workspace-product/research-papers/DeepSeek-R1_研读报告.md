| 维度 | 内容 |
|---|---|

## 1. 引言 (Introduction)

### 1.1 研究背景与核心问题

大语言模型（LLM）在规模化后表现出"涌现行为"（emergent behaviors），包括推理能力。然而，获取这种能力通常依赖于：
1. **预训练阶段**：需要海量计算资源
2. **后训练阶段**：依赖人类标注的思维链（Chain-of-Thought, CoT）示例进行监督微调（SFT）

现有主流范式（CoT 提示 + SFT 后训练）存在两个关键局限：
- **依赖人类标注**：高质量推理轨迹的标注成本极高，且引入人类认知偏差
- **范式受限**：模型被限制在复现人类思维模式，无法探索更优的、非人类式的推理路径

**核心研究问题（RQ）**：LLM 的推理能力能否通过**纯粹的强化学习**自主涌现，摆脱对人类标注推理轨迹的依赖？

### 1.2 文献综述与研究缺口

| 相关工作 | 主要观点 | 不足 |
|---|---|---|
| Kaplan et al. (2020), Wei et al. (2022a) | 模型规模化带来涌现能力 | 预训练成本过高 |
| Chain-of-Thought 提示 (Kojima et al., 2022) | "Let’s think step by step" 激发推理 | 依赖模型自身潜在能力上限 |
| SFT 后训练 (Chung et al., 2024) | 学习高质量多步推理轨迹 | 依赖人类标注，引入认知偏差，限制探索空间 |

**研究缺口**：现有方法无法在不依赖人类推理标注的前提下，激活预训练模型中已存在的推理潜力。本研究首次系统验证：**规则化奖励信号 + 纯 RL** 是否足以驱动复杂推理能力的自主发展。

### 1.3 研究目标与核心假设

- **总目标**：证明纯 RL 可替代 SFT 成为激发 LLM 推理能力的有效路径
- **DeepSeek-R1-Zero**：跳过 SFT，直接对 Base 模型应用 GRPO + 规则奖励，观察能否自主涌现推理行为
- **DeepSeek-R1**：引入冷启动数据 + 多阶段 RL 流程，在保持推理能力的同时改善可读性和语言一致性

## 2. 研究设计与方法

### 2.1 核心方法论：GRPO（Group Relative Policy Optimization）

GRPO 是 PPO 的简化变体，其核心创新在于**无需独立价值模型**，而是通过组内相对得分估算优势函数：

$$A_i = \frac{r_i - \text{mean}(\{r_1, r_2, \ldots, r_G\})}{\text{std}(\{r_1, r_2, \ldots, r_G\})}$$

**GRPO 相比 PPO 的优势**：
- 不需要训练价值模型（价值模型与策略模型规模相近，引入大量内存和计算开销）
- 长 CoT 生成场景下，价值模型在部分响应时预测最终奖励极为困难（生成内容可能被后续反思推翻）
- PPO 的每 Token KL 惩罚隐含约束响应长度，抑制了 CoT 的自主增长

### 2.2 奖励设计

**DeepSeek-R1-Zero** 采用纯规则奖励，分为两类：

1. **准确率奖励（Accuracy Reward）**：依据最终答案正确性判定（例如：数学问题要求答案写在 box 内，通过规则验证）
2. **格式奖励（Format Reward）**：强制要求推理过程包裹在 `<think>` 和 `</think>` 标签内，保证可解释性

$$Reward_{rule} = Reward_{acc} + Reward_{format}$$

> **关键决策**：不使用神经奖励模型（无论 outcome-based 还是 process-based），因为在大规模 RL 中极易发生 reward hacking，且重新训练奖励模型需大量计算资源。

**DeepSeek-R1** 在此基础上引入：
- **语言一致性奖励**：防止多语言混合（公式7）
- **人类偏好奖励模型**：针对 helpfulness 和 safety 的模型化奖励（公式5、6）
- **冷启动数据**：数千条展现对话式、人类对齐思维过程的推理数据

## 3. 结果与发现

### 3.1 DeepSeek-R1-Zero 的自我进化过程

<p align="center">
<img src="https://i.img402.dev/4py4cwq412.jpg" width="900"/>
</p>
<p align="center">图2：(a) DeepSeek-R1-Zero 在 AIME 2024 训练过程中的准确率变化；(b) 平均响应长度变化（来源：原论文 [Figure 1]）</p>

**关键发现**：
- **准确率跃升**：AIME 2024 Pass@1 从初始的 **15.6%** 提升至训练结束的 **77.9%**（使用 Cons@16 自洽解码达 86.7%），显著超越人类参赛者平均水平
- **思维时间自发增长**：响应长度从约 2,000 tokens 持续增长至约 20,000 tokens，模型自主学习用更长的推理链解决复杂问题
- **涌现"aha moment"**：在训练过程中，模型突然大量使用"wait"一词进行反思——这是模型自主发展出**自我验证**策略的明确信号

> Table 2（论文原文）展示了 DeepSeek-R1-Zero 的一个"aha moment"：模型在解题过程中突然停下来重新审视自己的推导步骤，用"Wait, wait. Wait. That's an aha moment"来标记反思点。

### 3.2 DeepSeek-R1 与中间版本对比

**表3（论文核心实验结果）关键数据**：

| 基准 | R1-Zero | R1-Dev1 | R1-Dev2 | R1-Dev3 | **R1** |
|---|---|---|---|---|---|
| AIME 2024 (Pass@1) | 77.9% | 59.0% | 74.0% | 78.1% | **79.8%** |
| MATH-500 (Pass@1) | 95.9% | 94.2% | 95.9% | 95.4% | **97.3%** |
| Codeforces (Percentile) | 80.4% | 84.5% | 90.5% | 92.1% | **96.3%** |
| MMLU (EM) | 88.8% | 89.1% | 91.2% | 91.0% | **90.8%** |
| IF-Eval (Prompt Strict) | 46.6% | 71.7% | 72.0% | 78.1% | **83.3%** |
| AlpacaEval2.0 (LC-winrate) | 24.7% | 50.1% | 55.8% | 62.1% | **87.6%** |
| ArenaHard (GPT-4-1106) | 53.6% | 77.0% | 73.2% | 75.6% | **92.3%** |

**分析**：
- **R1-Dev1**（仅冷启动 SFT）：指令跟随能力大幅提升（IF-Eval: 46.6% → 71.7%），但推理能力因缺乏 RL 而下降（AIME: 77.9% → 59.0%）
- **R1-Dev2**（+ 第一轮 RL）：推理能力全面恢复并超越 R1-Zero（Codeforces: 90.5%），语言混合问题得到控制
- **R1-Dev3**（+ 拒绝采样 + SFT）：通用能力（写作、代码工程）显著增强（Aider-Polyglot: 6.7% → 44.8%）
- **R1**（+ 第二轮 RL）：最终模型在推理与通用能力间取得最佳平衡，AlpacaEval2.0 相对 Dev3 提升 25%

## 4. 讨论

### 4.1 结果的深度解读

DeepSeek-R1-Zero 的成功揭示了一个深刻洞察：**预训练大模型已经具备复杂推理的潜在能力，所缺乏的只是一个足够强的奖励信号来激活它**。这挑战了"模型必须通过 SFT 学习人类推理模板才能推理"的传统假设。

"aha moment"的涌现是本论文最珍贵的发现：模型并非被教导"要反思"，而是在追求准确率最大化的过程中**自发发现**了反思策略的价值。这与人类认知发展中"顿悟"的现象高度相似。

### 4.2 理论贡献

1. **证明了 SFT 对 RL 的阻碍作用**：人类提供的"最优推理路径"并非模型学习的最优路径；跳过 SFT 直接 RL 允许模型探索更广阔的推理策略空间
2. **揭示了规则奖励的充分性**：对于可验证任务（数学、代码），精确的规则奖励足以驱动复杂推理行为，无需复杂的神经奖励模型
3. **提出了 RL 驱动的自我进化范式**：模型能力可以通过"hard questions + reliable verifier + sufficient RL compute"自主提升，而非依赖人类标注

### 4.3 实践启示

- **工业界**：对于具有明确验证器的任务（数学、代码），可直接采用纯 RL 路径训练，显著降低对高质量标注数据的依赖
- **学术界**：为"如何激活预训练模型潜在能力"提供了新范式——关键不在于更多人类示范，而在于设计更优的奖励信号
- **AGI 路径**：本研究为"通过可验证任务扩展实现超越人类推理"提供了实证支持

### 4.4 局限性与未来研究

| 局限性 | 说明 | 可能的解决方向 |
|---|---|---|
| 结构化输出与工具调用 | 工具使用能力（如搜索、计算器）仍有待提升 | 构建工具使用的 RL 环境 |
| Token 效率（过度思考） | 简单问题也生成过长推理链 | 动态计算资源分配优化 |
| 语言混合 | 仅在中英文上最优，多语言场景存在混合 | 扩展多语言冷启动数据 |
| Prompt 敏感性 | 少样本提示会降低性能 | 探索更鲁棒的提示策略 |
| 软件工程任务 | 长评估时间限制 RL 效率 | 异步评估或拒绝采样 |
| Reward Hacking | 不可验证任务难以构建可靠奖励 | 依赖更鲁棒的奖励模型 |

## 5. 结论

本研究通过 **DeepSeek-R1-Zero** 和 **DeepSeek-R1** 两个模型，系统证明了：

> **大规模强化学习可以在无需任何人类标注推理轨迹的前提下，自主激发大语言模型的复杂推理能力，包括自我验证、反思、多路径探索等高级推理模式。**

解锁这一潜力的关键不在于海量人类标注，而在于三个要素的结合：
1. **hard reasoning questions**（足够困难的推理问题）
2. **reliable verifier**（可靠的验证器）
3. **sufficient computational resources for RL**（充足的 RL 计算资源）

这一发现为未来通用人工智能的研究开辟了新路径：对于任何具有可验证答案的任务，机器都有可能通过 RL 自我进化，超越提供示范的人类。

## 方法公式化

```text
DeepSeek-R1-Zero = (DeepSeek-V3-Base + GRPO + 规则奖励) × 充足RL计算资源

其中:
  GRPO = 无需价值模型的策略优化
  规则奖励 = 准确率奖励 + 格式奖励
  充足RL计算资源 = 大 batch size + 长训练步数 + 超大半径clip

最终效果:
  推理能力 = f(问题难度, 验证器可靠性, RL计算量)
  （而非 = f(人类标注质量)）
```

## 最终双重总结

### 一句话总结（核心价值）

> DeepSeek-R1-Zero 通过纯强化学习（完全无需人类推理标注），在 AIME 数学竞赛基准上从 15.6% 跃升至 77.9%，证明大模型可以**自主涌现出自我验证、反思等复杂推理策略**——复杂推理能力的关键不在于人类示范的质量，而在于是否提供了足够困难的题目、可靠的验证器和充足的 RL 计算资源。

### 一句话总结（大白话版）

> 以前的 AI 需要人类一步一步教它怎么推理，结果这条路反而限制了 AI 的发挥；DeepSeek-R1-Zero 直接让 AI 自己摸索，只告诉它"答对了加分、答错了扣分"，结果 AI 自己学会了回头检查、换方法重试，甚至还会说"等一下，让我重新想想"——这是 AI 第一次在没有老师的情况下，自己悟出了"反思"这个高级技能。
