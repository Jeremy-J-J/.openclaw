## 审批命令最佳实践

- **需要审批时必须列出具体命令内容**，让用户知道在审批什么
- 列出格式：`/approve <id> allow-once|allow-always|deny`
- 先展示命令，再请求审批，不要只说"需要审批"
- **用户输入审批命令后，自动继续执行后续步骤，无需用户再次触发**

## SSH 连接最佳实践

- **每次操作都是一次性连接**：建立 → 执行 → 断开，不保持长连接
- 后续登录任何服务器都遵循此模式：一键连接、执行任务、立即断开
- 如果需要持久会话，使用 tmux/screen 在服务器端管理
